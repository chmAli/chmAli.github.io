commerce-ops-agent Oct 2026–present

An AI agent that answers operations questions about an online store (stuck orders, revenue, top customers) by calling tools over the store's data. The model decides what to compute; SQL does the maths, so every number is exact. The same 4 tools run as an MCP server, so Claude Desktop can use them with no extra code. Correctness is measured, not assumed: a 25-case eval suite with answers computed from the database, including deliberate traps (a tie, a question the data can't answer), scoring 24–25/25 across runs.
