# chmali.github.io

Personal portfolio — [chmali.github.io](https://chmali.github.io)

Hand-written HTML and CSS. No framework, no build step, no dependencies.

## Structure

- `index.html` — all content
- `styles.css` — design tokens in the `:root` block, light/dark via `prefers-color-scheme` + manual toggle
- `shots/` — product screenshots (images referenced but missing simply don't render)

## Run locally

Open `index.html` in a browser — that's it.
